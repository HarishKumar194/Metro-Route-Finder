# Metro-Route-Finder
#  Metro Route Finder using Dijkstra Algorithm

## Overview
This project finds the shortest metro route between two stations using **Dijkstra’s Algorithm**. It models stations as graph nodes and distances as weighted edges.

It also calculates **estimated fare based on distance**.

---

## Features
- Shortest path using Dijkstra’s Algorithm
- Priority Queue (Min Heap) optimization
- Route reconstruction using parent tracking
- Fare calculation system
- Clean modular design

---

## Algorithm Used
- Dijkstra’s Algorithm  
- Time Complexity: O((V + E) log V)

---

## Fare System
Fare is calculated as:

Fare = Distance × ₹2 per km

Example:
- Distance = 10 km  
- Fare = ₹20
